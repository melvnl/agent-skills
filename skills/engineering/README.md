# Engineering

Code and repository workflows.

- **[factory-init](factory-init/SKILL.md)**: Bootstrap (or `--verify`) the `.factory/` software factory in a repository.
- **[factory-router](factory-router/SKILL.md)**: Classify, size, and route each request in a factory repo to its workflow.

`factory-init/assets/factory-router.SKILL.md` is a bundled copy of `factory-router/SKILL.md`, installed into target repos. Edit the source and copy it over; `scripts/validate-skills.sh` fails on drift.

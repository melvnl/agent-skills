# melvin-security

Backend application security for services and integrations: the vulnerability classes that recur in reviews and incidents, each checked with a test that attempts the attack.

## Skills

- **[backend-security](skills/backend-security/SKILL.md)**: Authn and object-level authz (IDOR), mass assignment, injection, SSRF, webhook and callback verification, secrets, deserialization, abuse controls; each with an attack test.

## Agents

- **[security-auditor](agents/security-auditor.md)**: Independent, read-only audit for authz and IDOR, injection, SSRF, webhook verification, secrets and data exposure, with exploit scenarios.
